# Design tokens

Every widget renders entirely from a single token set, `ChartDesignTokens`
(`src/widgets/shared/theme.ts`). Two instances exist — `light` and `dark` — and
they are emitted to the document as CSS custom properties (`--sigil-*`). Widgets
never hard-code colors; they read these variables, which is what lets a single
View adapt to both themes and to the host's `prefers-color-scheme`.

This page is the live reference for the palette. It draws directly from the same
`light` / `dark` token objects the widgets use, so it can never drift from
production.

## Non-color scales

These are theme-independent (structural) and shared by both themes:

- **Spacing** — `--sigil-space-xs … --sigil-space-2xl` (4 / 8 / 12 / 16 / 24 / 32 px).
- **Radius** — `--sigil-radius-sm | md | lg | full` (4 / 8 / 12 / 999 px).
- **Typography** — IBM Plex Sans for labels/titles, IBM Plex Mono for ticks and
  numeric values, with a tabular-numeric value scale. Exposed as
  `--sigil-font-<step>-*`.
- **Motion** — `--sigil-duration-fast | base | slow` and matching easing curves.
